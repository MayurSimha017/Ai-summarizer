# 🧠 AI Summarizer – Full Stack Application

An intelligent AI-powered summarization tool that allows users to generate concise summaries from **text**, **web URLs**, and **images**. The app features a sleek **dark-themed UI**, customizable summary options, and integrates modern NLP and OCR technologies.

## 🚀 Features

- 🔗 **URL Summarization**: Extracts article content from any public link and generates a summary.
- 🖼️ **Image Summarization**: Upload images with text (e.g., screenshots, handwritten notes) and get summaries using OCR.
- ✍️ **Customizable Output**: Choose summary **length** (short, medium, long) and **tone** (formal, casual, neutral).
- 🌑 **Dark Theme UI**: Responsive and accessible design using modern UI libraries.
- ⚡ **Fast, scalable backend**: Built with Python and state-of-the-art language models.

---

## 🛠️ Tech Stack

### 💻 Frontend
- **React** with **Vite**
- **Tailwind CSS** for styling
- **shadcn/ui** components
- **Axios** for API communication

### 🔧 Backend
- **Python** with **FastAPI** (or Flask)
- **Hugging Face Transformers** (e.g., `bart-large-cnn`, `t5-base`)
- **OCR**: `pytesseract` or `easyocr`
- **Web Scraping**: `newspaper3k` or `BeautifulSoup`
